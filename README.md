# 基于机器学习的工业设备运行状态监测系统

> 制造智能技术课程设计 · 同时提供 B/S 与 C/S 两种客户端界面 · 基于工业设备振动数据 + Flask 后端，同时服务【浏览器 B/S】与【桌面 C/S】两种客户端，覆盖 ≥3 个课程章节。

## 功能

- 上传工业设备运行振动数据，后端自动跑 信号预处理 + 多域特征提取 + 机器学习状态识别
- 返回设备运行状态（正常 / 预警 / 异常 3 类）、置信度、健康度评分、严重等级
- SQLite 持久化监测记录，支持历史查询与统计分析
- 实时监测看板：监测总数、异常率、状态分布、健康度分布、SPC 单值控制图
- B/S 界面：浏览器打开 `index.html`（或启动后端后访问 5000 端口），无需安装客户端
- C/S 界面：`client/desktop_client.py` 桌面程序（tkinter），含连接管理、状态监测、结果展示、历史记录、SPC 看板，可一键启动本地服务器、一键打开网页版

## 两种架构对照（B/S 与 C/S）

| 对比项 | B/S（浏览器/服务器） | C/S（客户端/服务器） |
| --- | --- | --- |
| 客户端 | 浏览器（Chrome/Edge） | 桌面程序 `client/desktop_client.py`（tkinter） |
| 启动方式 | 双击 `启动检测系统.bat`（或 `python start.py`） | 双击 `启动桌面客户端.bat` |
| 适用场景 | 远程访问、演示答辩、跨平台 | 本地工位长期使用、离线操作 |
| 维护成本 | 升级只改服务器端，用户无感知 | 升级需更新客户端 |
| 交互能力 | 网页交互，可视化丰富 | 原生桌面交互，响应更快 |

两种客户端调用的是同一台服务器、同一套 REST 接口，体现前后端分离与体系结构知识点。

## 技术栈

- 服务器端：Flask + SQLite + SQLAlchemy
- 算法：小波降噪 + FFT频谱分析 + 包络分析（信号处理）+ 41维特征工程 + 随机森林/SVM/KNN/GBDT/决策树 多模型分类 + 孤立森林异常检测
- B/S 前端：原生 HTML + CSS/JS + ECharts 可视化
- C/S 客户端：Python 标准库 tkinter（GUI） + requests（HTTP），无需额外GUI依赖

## 快速启动

0. 安装依赖（仅首次）

```
pip install -r requirements.txt
```

1. 启动服务器（B/S 与 C/S 都依赖它）

- 方式一（一键）：Windows 双击 `启动检测系统.bat`，服务启动后浏览器自动打开 `http://127.0.0.1:5000`；关闭命令行窗口即停止服务。
- 方式二（手动）：`python start.py`（自动开浏览器）或 `python run.py`（只起服务）。

2a. 使用 B/S 界面

服务器启动后，浏览器访问 `http://127.0.0.1:5000`，上传设备运行数据 → 开始状态监测。

2b. 使用 C/S 桌面客户端

- 双击 `启动桌面客户端.bat`（或 `python client/desktop_client.py`）；
- 顶部确认状态灯为"已连接"（若服务器未启动，可直接点界面上的【启动本地服务器】）；
- 左侧"选择文件"或下拉"载入样例" → 点【开始监测】，右侧看结果与状态判定；
- 下方两个页签查看【历史监测记录】与【质量统计看板（SPC）】；
- 点【打开网页版(B/S)】可随时切换到浏览器界面。

## 数据集

- 基于工业设备运行振动特征生成的模拟数据集
- 3 类 × 400 条 = 1200 条样本，每条 1024 个采样点，采样率 12000Hz
- 原始数据入 `data/device_dataset.csv`
- 预处理脚本 `data/preprocess.py` 内置在 data 目录，内置 3 张测试数据样例，可直接验证全流程。

## 覆盖的课程章节（≥3 个技术方向）

| # | 课程技术方向 / 章节 | 对应知识点 | 代码位置 | B/S 体现 | C/S 体现 |
| --- | --- | --- | --- | --- | --- |
| 1 | 智能感知与信号处理 | 小波降噪、FFT、包络分析、滤波 | backend/algorithms/preprocessing.py | 波形图、频谱图 | 结果图、信号预览 |
| 2 | 特征工程与模式识别 | 时域/频域/时频域特征提取 | backend/algorithms/feature_extraction.py | 特征重要性图 | 特征值面板 |
| 3 | 机器学习与智能诊断 | 随机森林/SVM/KNN/GBDT 多模型分类 | backend/algorithms/fault_classifier.py | 模型管理页 | 模型选择、置信度显示 |
| 4 | 异常检测与预测性维护 | 孤立森林、SPC控制图、健康度评分 | backend/algorithms/anomaly_detection.py | SPC看板、健康度 | 异常判定、健康度仪表盘 |

## 接口一览（B/S、C/S 共用）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 返回 B/S 前端页面 |
| GET | `/api/health` | 健康检查（客户端探测服务器在线状态） |
| POST | `/api/diagnose/upload` | 上传数据文件，返回状态类别/置信度/健康度/波形/频谱 |
| GET | `/api/diagnose/records?limit=n` | 历史监测记录 |
| GET | `/api/diagnose/stats` | 状态分布/健康度/SPC 聚合数据 |
| GET | `/api/model/list` | 已训练模型列表 |
| POST | `/api/model/train` | 触发模型训练 |
