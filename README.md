# 工业设备运行状态监测课程设计
本仓库用于保存课程设计全部资料。

## 文件说明
1. 选题说明.md：项目选题背景、研究意义
2. 方案设计.md：整体方案、技术路线、实施计划、参考文献
3. 学习笔记.md：课程学习总结
4. prompt文件夹：AI交互记录、提示词文档
5. data文件夹：数据集说明与预处理资料
## 数据准备阶段
1. 数据来源：采用CWRU轴承故障公开数据集，数据集链接存放于 /data/data_intro.md。
2. 数据预处理：完成信号切片、归一化、数据集划分；预处理流程说明保存在 data 目录。
3. AI提示词记录：与AI沟通记录保存在 /prompt/chat_log.json，后续阶段持续更新。
