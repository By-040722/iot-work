# 工业设备运行状态监测课程设计

本仓库用于保存课程设计全部资料。

## 文件说明

1. **选题说明.md**：项目选题背景、研究意义
2. **方案设计.md**：整体方案、技术路线、实施计划、参考文献
3. **学习笔记.md**：课程学习总结
4. **prompt文件夹**：AI交互记录、提示词文档
5. **data文件夹**：数据集说明与预处理资料

## 数据准备阶段

1. **数据来源**：采用和鲸社区（Heywhale）轴承振动信号公开数据集，数据集链接：https://www.heywhale.com/mw/dataset/69a7d5b64a5a2f8d77925643
2. **数据预处理**：剔除缺失值与异常值、特征归一化、按照7:3划分训练集与测试集；预处理流程说明保存在 data 目录。
3. **AI提示词记录**：与AI沟通记录保存在 `/prompt/chat_log.json`，后续阶段持续更新。

## 模型搭建阶段

1. **模型选择**：采用 1D-CNN（一维卷积神经网络）模型，该模型适合处理一维振动信号序列数据。
2. **代码实现**：模型的搭建与训练代码将保存在项目根目录下（如 `model_train.py`）。
3. **AI提示词记录**：相关沟通记录已同步更新至 `/prompt/chat_log.json`。
