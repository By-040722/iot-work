# 基于振动信号分析的旋转机械轴承智能故障诊断系统

> 制造智能技术课程设计项目

## 项目简介

本项目面向工业旋转机械的轴承故障诊断需求，设计并实现了一个基于B/S架构的智能故障诊断系统。系统能够对轴承振动信号进行自动预处理、特征提取、故障分类与健康度评估，提供可视化的人机交互界面，支持数据上传、在线诊断、结果查询与模型管理。

## 技术方向

本项目综合运用《制造智能技术》课程4个技术方向：

| 序号 | 技术方向 | 对应课程章节 | 核心算法 |
|:---:|---------|------------|---------|
| 1 | 智能感知与信号处理 | 第3、4章 | 小波降噪、带通滤波、3σ异常值去除、分帧、归一化 |
| 2 | 特征工程与模式识别 | 第4、5章 | 时域/频域/时频域特征、小波包分解、希尔伯特包络解调 |
| 3 | 机器学习与智能诊断 | 第6、7、8章 | SVM、随机森林、KNN、决策树、GBDT、交叉验证 |
| 4 | 异常检测与预测性维护 | 第9、10章 | SPC控制图、孤立森林、健康度评估、退化趋势预测 |

## 快速开始

### 1. 环境要求

- Python 3.9+
- 现代浏览器（Chrome / Edge / Firefox）

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 生成模拟数据集

```bash
python scripts/generate_dataset.py
```

这将在 `data/` 目录下生成：
- `bearing_dataset.csv`：主数据集（4类×300条×1024点）
- `test_signal_outer.csv`：外圈故障测试信号
- `test_signal_normal.csv`：正常状态测试信号

### 4. 启动系统

```bash
python run.py
```

启动后访问：http://127.0.0.1:5000

### 5. 使用流程

1. **数据管理**：上传数据集（或使用生成的模拟数据集）
2. **模型管理**：选择数据集，训练模型（5种模型自动对比）
3. **在线诊断**：上传振动信号文件，查看诊断结果
4. **历史记录**：查看历史诊断记录和统计

## 算法说明

### 数据预处理
- **异常值去除**：基于3σ原则，用中位数填充
- **小波降噪**：db4小波4层分解，软阈值收缩
- **带通滤波**：巴特沃斯4阶带通滤波（10Hz-5000Hz）
- **归一化**：Z-score / Min-Max / MaxAbs三种方法
- **分帧**：帧长1024，帧移512

### 特征提取（41维）
- **时域特征（16维）**：均值、标准差、RMS、峰值、峰峰值、偏度、峭度、峰值因子、脉冲因子、裕度因子、波形因子、能量等
- **频域特征（13维）**：频谱重心、频谱方差、频谱峭度、频谱熵、主频、5个频带能量比
- **时频域特征（8维）**：小波包3层分解8频带能量比 + 能量熵
- **包络谱特征（4维）**：希尔伯特变换包络解调，包络谱峰值频率和峭度

### 故障分类
- **5种模型**：SVM（RBF核）、随机森林（100棵树）、KNN（k=5）、决策树（CART）、梯度提升树（GBDT）
- **评估指标**：准确率、精确率、召回率、F1分数、混淆矩阵、5折交叉验证
- **模型选择**：自动选择F1分数最高的模型作为默认模型
- **模型持久化**：joblib序列化保存

### 异常检测与健康评估
- **SPC异常检测**：基于正常数据建立3σ控制限，检测RMS和峭度超限
- **孤立森林**：基于正常特征训练，输出异常分数
- **健康度评估**：综合RMS（40%）、峭度（35%）、峰值因子（25%），输出0-100分
- **健康等级**：优秀(≥80)、良好(60-80)、注意(40-60)、恶化(20-40)、严重(<20)
- **退化趋势预测**：线性回归外推，预测未来健康度和预计失效时间

## API接口

### 诊断接口
- `POST /api/diagnose/upload` - 上传文件并诊断
- `GET /api/diagnose/records` - 获取诊断记录列表
- `GET /api/diagnose/record/<id>` - 获取单条记录详情
- `DELETE /api/diagnose/record/<id>` - 删除记录
- `GET /api/diagnose/stats` - 获取诊断统计

### 数据接口
- `POST /api/data/upload` - 上传数据集
- `GET /api/data/list` - 获取数据集列表
- `GET /api/data/<id>` - 获取数据集详情
- `DELETE /api/data/<id>` - 删除数据集
- `GET /api/data/<id>/preview` - 预览数据集

### 模型接口
- `POST /api/model/train` - 训练模型
- `GET /api/model/list` - 获取模型列表
- `POST /api/model/select` - 设置默认模型
- `GET /api/model/feature-importance` - 获取特征重要性
- `DELETE /api/model/<id>` - 删除模型

### 系统接口
- `GET /api/system/info` - 系统信息
- `GET /api/system/health` - 健康检查

## 数据库设计

### 诊断记录表（diagnosis_records）
存储每次诊断的完整信息，包括故障类型、置信度、健康度、特征摘要等。

### 数据集信息表（datasets）
存储上传的数据集元信息，包括样本数、特征数、类别分布等。

### 模型信息表（models）
存储训练好的模型信息，包括各评估指标、是否最优模型等。

### 系统日志表（system_logs）
存储系统运行日志，包括诊断、上传、训练等操作记录。
